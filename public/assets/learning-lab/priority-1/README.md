# Safe Roads World — Learning Lab Priority 1

Transparent PNG artwork for occupant protection, motorcycle safety, helmet testing and pedestrian missions.

## Phaser animation

Each pedestrian folder contains `standing.png`, `walk-a.png` and `walk-b.png`.
Alternate the two walking frames at a restrained rate and use the standing image when motion stops.

All instructional labels, safety-feature highlights and interaction hotspots should be drawn in code.
