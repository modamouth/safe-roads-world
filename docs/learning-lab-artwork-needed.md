# Learning Lab: artwork needed

**For:** the illustrator / art team producing Safe Roads World graphics
**Date:** 14 October 2026

Most Learning Lab illustrations are drawn in code from simple shapes as placeholders. This list says which ones need proper artwork, what each image must show, and the format. Real artwork already in use: the white SUV, the five parked vehicles (taxi, two sedans, bakkie, box truck), the oncoming pickup, the crash-lab car and barrier photos, the Windhoek skyline, the map and the character.

## General format (all items)

- **Style:** match the existing parked vehicles and map art: semi-realistic 3D game-art, soft daylight, Namibian setting.
- **File:** PNG or WebP with a **fully transparent background**, no shadow, no glow, no text, no logos or number plates.
- **Size:** at least 1024 px on the long side; the subject fills the frame.
- **Sets:** where an item has states (for example "loose" and "firm"), every state must be the **same object at the same angle, size and position**, so the game can swap between them without jumping. Make the first image, then edit it for the others.
- **People:** diverse Namibian people; no injuries shown, ever. Crash-test dummies may be shown.

## Prompt template

```
[SUBJECT AND VIEW, e.g. "Side view of a rear-facing child car seat fitted on
the back seat of a car, with a small crash-test dummy strapped in"].
Semi-realistic 3D game-art style, soft daylight, clean and crisp.
Isolated on a fully transparent background. No shadow, no glow, no text,
no logos. Whole object in frame, centred.
```
For state variants, edit the first image: "Keep this image identical in every way (same object, angle, size, position, lighting). Only change: [state]."
